- 2026-09-24: shipped the third microsite, `food-hygiene-registers` (commit 0899071, feat/stories). No vendored source was left unused, so the `food-hygiene-authorities` adapter went into `uk-open-data-connectors` first (PR #16, branch `feat/connectors/add_fsa_food_hygiene_adapter`, 13 unit tests, `npm run check` and the live smoke test both green) and was vendored with `node scripts/sync-connectors.mjs --from /tmp/connectors-fsa`. Environment notes: the agency station count flickers between 2,094 and 2,095 on calls minutes apart, so the gauge copy carries the build's figure and its data note now says the total moves between builds; and `uk-open-data-connectors` is mid-refactor on PR #9 (`refactor/connectors/make_repo_uk_only`, package scope renamed to `@open-data-connectors`), which will fail the `@nzlab` package-name check in `scripts/sync-connectors.mjs` once it merges, so the next sync needs the script taught the new scope first.
- 2026-09-25: shipped the fourth microsite, `cycle-hire-docks` (commit 8edbf73, feat/stories, plus 53668be, a copy fix). TfL's Santander Cycles docking stations needed a new source, so the `tfl-bike-points` adapter went into `uk-open-data-connectors` first (PR #19, stacked on the unmerged FSA PR #16 because the vendored copy has to carry both, 18 unit tests, a six-station fixture, `npm run check` and the live smoke test green across all five UK sources) and was vendored with `node scripts/sync-connectors.mjs --from /tmp/connectors-tfl`. The page draws all 798 stations as a dot plot stacked at their docking points, with Jubilee Plaza at Canary Wharf out front at 63. The audit found the real reason the published stories read stale: every build-time fetch carried `cache: 'no-store'`, which Next treats as a dynamic fetch, and the static export refuses to prerender a route that makes one, so all four stories had been falling back to their committed snapshots on every build since yesterday (the fixture refresh in that iteration hid it). The five fetches now use `next: { revalidate: 1 }`, which prerenders and re-reads each source per build, and the source notes are filled at build time from the same read the chart draws, so their totals and their date always match the page. Three copy figures moved for the same reason and are no longer quoted in prose: the agency station total (2,095, then 2,093, then 2,097 across calls an hour apart), the FSA establishment total (612,721 to 612,772) and TfL's docking-point total (20,992 to 20,942 inside an hour, as stations came out of service). Verified after the deploy: gauge 2,093, food 612,772, cycle hire 798/20,942, ONS 338/310/281, all matching a fresh call, production READY about 60s after each push. Environment notes: `uk-open-data-connectors` is still mid-refactor on PR #9 (scope rename to `@open-data-connectors`), so the next sync needs the same stacked base and `scripts/sync-connectors.mjs` will need to accept the new scope once #9 merges; and port 3000 is still held by another `next-server`, so the gates run as `E2E_PORT=3100 npm run check` and `E2E_PORT=3100 git push`.
